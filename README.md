# AgriQueue 🌾

## Agricultural Procurement & Digital Queue Management System

AgriQueue is a digital agricultural procurement and queue management system designed to make the crop procurement process faster, more organized, and transparent.

The system manages the complete workflow from farmer slot booking and digital token generation to weighing, quality inspection, receipt generation, payment, and administrative analytics.

---

## 🚀 Features

### 👨‍🌾 Farmer
- Secure login
- Select procurement center
- Select date and crop
- Enter estimated quantity
- Book an available time slot
- Generate a digital token
- View booking history
- Track booking status
- Cancel eligible bookings

### 👷 Staff
- View today's procurement queue
- Check in farmers
- Manage queue status
- Call farmers for weighing
- Record gross and empty vehicle weight
- Calculate net weight
- Generate procurement receipts
- Process payments

### 🔍 Inspector
- View pending quality inspections
- Record crop grade
- Record moisture percentage
- Record damaged percentage
- Add inspection remarks
- Accept or reject crop quality

### 👨‍💼 Admin
- View procurement statistics
- Monitor farmer activity
- Monitor queue status
- View crop received
- View quality grades
- Monitor rejected procurement
- View overall system analytics
